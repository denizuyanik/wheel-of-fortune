# Getting Started 

This app was created using the [Wix CLI](https://dev.wix.com/docs/wix-cli/guides/about-the-wix-cli). Develop and iterate on your app in the [unified workspace](https://dev.wix.com/docs/build-apps/develop-your-app/app-dashboard-setup/unified-workspace/about-the-unified-workspace). Chat with the AI agent to make changes or edit the code directly in the workspace's [code tab](https://dev.wix.com/docs/build-apps/develop-your-app/app-dashboard-setup/unified-workspace/about-the-code-tab). When you're ready, click **Release** in the top-right corner to release a new version of your app.

Once released, you can [submit your app for review](https://dev.wix.com/docs/build-apps/launch-your-app/app-distribution/submit-your-first-app-version) to publish it on the [Wix App Market](https://www.wix.com/app-market), or distribute it by [sharing an install link](https://dev.wix.com/docs/build-apps/launch-your-app/app-distribution/share-an-app-install-link).
